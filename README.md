## 🎉 Smart Event Dashboard

A simple frontend project to manage events using HTML, CSS, and JavaScript.
Users can add, view, and delete events easily through a clean interface.

# 🚀 Features

➕ Add new events

🗑️ Delete individual events

❌ Clear all events

📌 Add sample events

⌨️ Keyboard key detection (DOM demo)

🎨 Responsive and modern UI


# 🛠️ Tech Stack

HTML

CSS

JavaScript (DOM Manipulation)
